Frontend Composables

useFilters.js
Singleton — one instance shared across all components. Holds the 4 global filter refs. Views watch these to know when to re-fetch.
selectedPeriod selectedWarehouse selectedCategory selectedStatus getCurrentFilters() resetFilters()
useI18n.js
Locale toggle (en / ja). The locale also drives currency: English → USD, Japanese → JPY. Use t() for all user-visible strings.
locale t() currency
useAuth.js
Mock authentication. Also provides a task list that the UI merges with tasks returned from the backend API.
